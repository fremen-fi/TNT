Help

TNT streamlines audio workflows for broadcast professionals: Transcode, Normalize, Tag.

Workflow

  1. Add files via "+ Files" or drag and drop onto the queue
  2. Set an output folder
  3. Configure in Fast, or use Advanced + Processing for fine control
  4. Click Process — files appear in the output folder as they finish

Tabs

  • Fast — three one-click presets for common use cases
  • Advanced — full control over format and encoding parameters
  • Processing — dynamics, EQ and loudness chain; active only when Advanced mode is selected
  • Metadata — read and write ID3/Vorbis tags for a selected file

Presets

  • Small file (AAC 256 kbps) — compressed, balanced quality/size
  • Most compatible (MP3 320 kbps) — universal playback
  • Production (PCM 48 kHz/24-bit) — uncompressed broadcast quality

Normalize applies EBU R128 (−23 LUFS, −1 dBTP) to all processed files.

Format selection

AAC, Opus, MP3, PCM (WAV), or FLAC. Sample rate and bit depth apply to PCM only; bitrate to AAC/Opus/MP3; compression level (0–10) to FLAC and Opus.

Options

  • Normalize — applies BS.1770-5 loudness correction, alters audio
  • Write RG tags — writes ReplayGain metadata only; mutually exclusive with Normalize; not available for PCM
  • Do not transcode — preserves the original encoding while writing tags
  • Speech — Opus VoIP-optimized encoding; do not use for music

Dynamics

  • Off — no compression
  • Light — gentle 2.5:1 for well-recorded content
  • Moderate — broadcast-style 3.5:1 for podcasts and music
  • Broadcast — five-band adaptive compression for radio/mobile

EQ target curves

Off, Flat, Speech, Broadcast — attenuation-only adjustments capped at ±10 dB.

Processing order

  1. EQ
  2. De-esser (with EQ)
  3. Dynamic normalisation
  4. Dynamics
  5. Loudness normalisation

Watch mode monitors a folder and processes new files automatically. TNT must remain running. Watch ignores existing files — process them first via "+ Folder", then enable Watch for newcomers.

AAC

High-quality lossy compression. ~1 MB per 30 s @ 256 kbps. Two encoders: Fraunhofer FDK (all platforms) and Apple AudioToolbox (macOS only).

Opus

Modern codec with strong low-bitrate performance and low delay. 12–510 kbps.

MP3

Universal compatibility. 320 kbps recommended; ~1.2 MB per 30 s.

FLAC

Lossless, ~40–60% of PCM size. Compression level 0–10.

PCM (WAV)

Uncompressed. Sample rate (44.1–192 kHz) × bit depth × channels = bitrate. ~8.6 MB per 30 s @ 48 kHz/24-bit stereo.
